## 📖 Overview

**streamx24** is a **Full-Stack Web App** built with **TypeScript / Next.js** and **PostgreSQL**.

---

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- PostgreSQL running locally (or connection string to hosted instance)

### Installation

```bash
git clone https://github.com/rohitbhure65/streamx24.git
cd streamx24
npm install
```

### Running the Project

```bash
npm run dev
```
